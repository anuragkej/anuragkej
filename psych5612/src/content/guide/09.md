## Why memory changes the problem

A sequential circuit's output can depend on internal state as well as its current input. State summarizes relevant history. Presenting the same input twice can therefore produce different outputs. A traffic sensor reading has different consequences when one road is green than when the other road is green.

Feedback can preserve information, but merely looping the next-state wires back creates timing problems. Different paths have different delays, and an output can race around the loop before other signals settle. Clocked storage separates the computation of a proposed next state from the moment that state becomes current.

## The abstract FSM

An FSM has a finite set of states, inputs and outputs, an initial/reset state, a next-state function N, and an output function F. In the course notation: y(t) = F(x(t), q(t)) and q(t+1) = N(x(t), q(t)). F and N are finite functions. A Moore machine's output depends only on state; a Mealy machine's output can also depend directly on current input.

A state diagram uses circles for states and arrows for transitions. Labels specify the inputs/conditions triggering each transition. Outputs may be written inside states for a Moore machine or on transitions for a Mealy presentation. Count circles, not arrows, to count states. Self-loops are real transitions that preserve the state.

## Course traffic-light controller

The L08 controller has four states and traffic sensors TA and TB. Its state table is:

| Current state | Outputs | Input condition | Next state |
| --- | --- | --- | --- |
| S0 | A green; B red | TA = 1 | S0 |
| S0 | A green; B red | TA = 0 | S1 |
| S1 | A yellow; B red | Any | S2 |
| S2 | A red; B green | TB = 1 | S2 |
| S2 | A red; B green | TB = 0 | S3 |
| S3 | A red; B yellow | Any | S0 |

Reset selects S0. In S0, TB does not determine the transition; TA does. In S2, TA is irrelevant to the transition; TB matters. Yellow lasts one transition interval in this simplified model. The original diagrams are at L08 pp. 11-15. Different readings use different simplified controllers; do not accidentally combine their rules.

**Example trace:** start S0 with TA = 1 → remain S0. Next TA = 0 → S1. Next clock → S2 regardless of sensors. If TB = 1 → remain S2. When TB = 0 → S3, then S0. The same pair of sensor values can produce different next states depending on current state, demonstrating the importance of memory.

## Encoding states and implementing the functions

Four states can be encoded by two bits: S0 = 00, S1 = 01, S2 = 10, S3 = 11. Generally k bits can encode 2^k states. Once state, input, and output symbols are encoded, the transition and output tables become Boolean functions implementable with combinatorial circuits.

Binary encoding is compact. One-hot encoding uses one bit per state, with exactly one asserted for a valid state. Dally & Harting illustrate how this can simplify next-state logic: the input to a state's flip-flop represents the OR of transition conditions leading into that state. More bits can buy simpler logic. Reset initializes a valid state; invalid encodings need consideration in a real design.

The reading's Verilog/state-table discussion is another notation for the same organization: stored current state, combinatorial next-state logic, and output logic. The essential cognitive-science point is systematic implementation, not memorizing a particular programming syntax.

## Latches versus registers

**A latch is level-sensitive:** during its transparent phase, changes in input can pass through; in its opaque phase it holds its value. A flip-flop is edge-triggered. In L08, a register abstracts clocked storage built from complementary latch phases. A multi-bit register stores a bit pattern using multiple storage elements.

> **Precise register definition:** On the rising clock edge, the register captures its data input as its new internal state; between rising edges it retains the previously captured state, provided setup/hold timing requirements are met. The output reflects that stored state, with a physical clock-to-output delay. Do not say it changes for the whole time the clock is HIGH; that describes a transparent latch rather than the rising-edge behavior requested in Q13.

A basic bistable element has two stable states and can store a bit. In an RS storage example, set/reset inputs drive the stored value and neither active input allows retention. The assigned sources use particular circuit conventions; do not generalize every simultaneous set/reset case without checking the circuit. Feedback circuits can also be astable, as with a ring oscillator, or enter an indeterminate/metastable condition. Not every loop is useful, well-behaved memory.

## Synchronous discipline: the important wording discrepancy

Q12 names the four conditions in Harris & Harris. On PDF p. 28, printed p. 121, the four composition conditions are:

1. Every circuit element is either a register or a combinational circuit.
2. At least one circuit element is a register.
3. All registers receive the same clock signal.
4. Every cyclic path contains at least one register.

L08 p. 28 presents a related four-item teaching list: component types; common clock; register on every cycle; and stable register inputs during the clock-edge aperture. It incorporates the dynamic timing requirement instead of separately listing “at least one register.” Both ideas matter. For Q12, a robust four-bullet preparation answer can put “at least one is a register” into the first bullet and retain the slide's timing requirement as the fourth; this includes every condition from both sources. Do not silently learn only one list and forget the other.

## Dynamic discipline and the clock edge

Setup time is the interval before the active edge during which the data input must be stable. Hold time is the interval after the edge during which it must remain stable. The aperture includes both. The register needs a stable value to capture, not a value changing at the critical instant. These constraints are specifically emphasized in Harris §3.5.1, PDF p. 33.

```widget
setup-hold
```

Conceptually, the clock period must allow the previous registers' outputs to emerge, the combinatorial logic to settle, and the next registers' setup requirement to be met. Hold constraints concern changes arriving too soon after an edge; slowing the clock alone does not fix every hold problem. The main exam target here is the meaning of stable input around the edge, not an unsupported claim that all physical changes happen simultaneously.

Synchronous discipline lets us reason in discrete clock cycles, while the underlying voltages and delays remain continuous. Asynchronous inputs and communication between clock domains require care; synchronizers reduce the chance that uncertain timing propagates. Reliability is an engineering guarantee with limits, not magical elimination of all possible failure.

## A simple exam-ready FSM you can draw

Practice example created for this guide: a two-state toggle has states OFF and ON. Input x = 0 keeps the state; x = 1 changes to the other state. Output y = 0 in OFF and y = 1 in ON. The next-state equation is q_next = q XOR x; output y = q. Starting OFF, inputs 1,0,1,1 yield states ON,ON,OFF,ON after the four updates. This is a two-state Moore machine.

## Second important fact about computation

> Technologies exist such that, in principle, for any FSM M = <F,N>, a physical device can be constructed that implements M within bounded engineering parameters: clock frequency f, power consumption W, failure rate epsilon, mass m, cost C, and so on. Multiple realizations of the same FSM are possible. [L08, p. 31.]

The construction is no mystery now: encode symbols/states; implement F and N with combinatorial logic; store current state in a register; update under the synchronous rules. The same abstract machine can have different physical realizations.
