## Abstraction and discipline

Abstraction hides lower-level implementation detail behind a useful description. A programmer calls a function based on its interface and promised behavior without tracking every transistor. An engineer treats a gate as implementing a Boolean function without repeatedly solving its complete analog physics. This resembles your CS connection: abstraction keeps attention on relevant behavior and makes larger systems easier to understand.

Discipline is intentionally restricting design choices so one can work more productively at a higher level of abstraction. It sacrifices some freedom to gain reliable composition and simpler reasoning. Hierarchy decomposes a system into parts; modularity gives parts clear interfaces; regularity reuses consistent patterns. These principles make very complex computers tractable.

Digital discipline restricts physical signals to designated discrete interpretations and constrains components so valid inputs yield valid outputs under specified timing conditions. All electronic circuits remain physical analog systems. A digital system does not escape continuous voltage; it uses intervals of voltage to stand for discrete values.

## Binary representation

A bit has two possible values. An n-bit pattern has 2^n possibilities. Bits can encode Boolean truth, quantities, letters, categories, or states. Binary positional notation weights places by powers of two: 1011 represents 8 + 0 + 2 + 1 = 11 under the unsigned convention. Decimal uses powers of ten; hexadecimal groups four bits into one of sixteen symbols. A fixed width limits the representable range. A pattern's meaning depends on the chosen representation, not just its shape.

Do not confuse an input that can take any natural number with a fixed-width input that can take finitely many values. The former is an unbounded mathematical domain; the latter can be enumerated in principle even if the table is huge.

## Finite functions and finite Boolean functions

A finite function has finitely many input variables and output variables, and each variable has a finite set of possible values. All input combinations can therefore be enumerated. In notation: (y1,...,ym) = F(x1,...,xn).

> A finite Boolean function adds the restriction that every input and output is binary. For n binary inputs there are 2^n input rows in a complete truth table; for m outputs each row specifies an m-bit result. There are 2^m possible output patterns, but the usual truth table is not required to have 2^m output columns. Every finite function can be encoded as a Boolean function by choosing bit patterns for its possible values.

**Example from the lectures:** adding two decimal digits is finite when each input is restricted to 0-9 and the output is a two-digit result. A spell checker restricted to four-letter strings over a fixed alphabet is finite. An unrestricted function on all natural numbers has a different kind of domain.

## Logic levels and noise margins

The sender guarantees output voltages in relatively tight ranges. The receiver accepts a somewhat wider range. That gap lets small disturbances occur without changing the interpreted bit.

| Symbol | Meaning |
| --- | --- |
| VOL | Maximum voltage guaranteed for a LOW output |
| VIL | Maximum voltage accepted as a LOW input |
| VIH | Minimum voltage accepted as a HIGH input |
| VOH | Minimum voltage guaranteed for a HIGH output |

For positive margins, VOL < VIL and VIH < VOH. LOW noise margin = VIL - VOL. HIGH noise margin = VOH - VIH. Input voltages between VIL and VIH are in the undefined/forbidden region; they do not have a guaranteed Boolean interpretation. The physical wire can pass through that region during transitions, which is why timing matters.

Practice values, not the course's fixed hardware parameters: VOL = 0.1 V, VIL = 0.3 V, VIH = 0.7 V, VOH = 0.9 V. Each noise margin is 0.2 V. A HIGH output at 0.9 V that loses 0.15 V is still accepted as HIGH at 0.75 V. A disturbance beyond the allowed margin no longer carries the same guarantee.

## Why a buffer is not physically redundant

The buffer's truth table is 0 → 0 and 1 → 1, so logically Y = A. Physically it can regenerate a valid but degraded input into a stronger valid output level. In the practice example, 0.75 V at its input can become at least 0.9 V at its output, preserving logical 1 while restoring the voltage margin for the next stage. Its power supply provides the energy; a bare wire does not perform that active restoration.

This is why the digital abstraction hides the buffer's purpose: the Boolean level reports “same bit,” while the analog level reveals useful signal restoration and drive. A buffer does not reconstruct any arbitrarily corrupted bit, and its logical guarantee does not extend to undefined input voltages.

## Static discipline and delays

Static discipline requires valid input voltages to produce valid output voltages after the specified propagation delay. Contamination delay, tcd, is the minimum time after an input change before an output may leave its old logical region. Propagation delay, tpd, is the maximum time needed for outputs to reach their final logical regions. Between those bounds, do not assume a stable old or final answer.

The logical description Y = F(X) describes settled behavior, not instantaneous physics. Gates take time; manufacturing variation, voltage, load, and temperature can affect delay. Maintaining an abstraction requires respecting its physical conditions.

## Transistors and the abstraction ladder

A transistor can act as an electrically controlled switch. In the familiar CMOS picture, complementary devices connect an output toward supply or ground depending on the input; this can implement inversion and other gates. Gates combine into circuits; circuits into datapaths and control systems; these support instruction sets, operating systems, and applications. A transistor is not literally a Boolean proposition, but its controlled behavior supports that abstraction.

The three major computer components emphasized in the slides are datapath, control, and memory. The datapath performs operations on data, control determines which operations occur, and memory retains instructions/data/state. The kitchen analogy separates the thing doing transformations, the instructions/control organizing them, and the storage of ingredients/intermediate results.
