## Cursor Cloud specific instructions

This repository is a **GitHub profile README** (`username/username` pattern). It contains only a single `README.md` file with HTML/Markdown that GitHub renders on the user's profile page.

- **No dependencies, build steps, tests, or lint checks** — the repo has no `package.json`, no source code, and no CI.
- **No services to run** — the "application" is the rendered Markdown/HTML displayed by GitHub.
- To verify changes, inspect `README.md` for valid HTML structure and render it in a browser.
